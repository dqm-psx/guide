    Breeding terms
    Pedigree
    Your first parent. Swapping parents can change the result.
    Mate
    The second parent.
    + value
    The breeding bonus beside a monster’s name. A threshold applies to either parent individually.
    Base table
    The offspring for an ordered pair before special breeding rules apply.
    Ordinary shrine
    Breed monsters from the same save. Some pairs produce a different offspring at higher + values.
    First copy
    A recipe where neither parent is the desired offspring.
    Breeding room
    Breed across two saves from the title screen. Certain pairs have exclusive results here.
    Eligible parents
    Confirm each parent’s sex and level in game before breeding.

    Either parent can meet a + threshold. In the title-screen Breeding room, each player’s monster is their pedigree.

    Sources & coverage

    The guide uses the PlayStation releases of Terry’s adventure and Cobi and Tara’s adventures. Campaign scripts, fixed maps, learning requirements and breeding rules have been checked against the v1.0.73 English disc.

    English patch release · Verification notes · Compare translation editions

    Names, library wording, skill/location labels, and the latest patch version update automatically from the translation project's public export. Publication is checked every four hours. Gameplay verification is a separate check against a release build; a text update does not advance it. All shipped data works offline.
