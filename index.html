    05Read the table

    Order is part of the recipe

    The pedigree selects a row and the mate selects a column. A + B and B + A are separate entries. The result panel compares both automatically.

    A base result is only a starting point

    This resource shows the base table, documents + value rules, and identifies title-screen Breeding room overrides. Read any conditional notice shown with a pair. It does not check the parents’ breeding eligibility or availability.

    Names belong to this build

    The full English name helps you identify the monster; the shorter in-game name helps you locate it in the menus. Numbered form labels are editorial aids for species that share a native name. Other localizations and later games may use different names or recipes.

    Extra slots are kept for completeness

    Extra and internal entries are hidden by default. Enable them below the name index to inspect the original table’s complete coverage. Their presence does not establish that they are obtainable.

    Source, coverage, and verification

    The embedded data is a fixed snapshot for v1.0.61-CURRENT. This file makes no network requests and does not update itself.
